================================================================================
                    BILLNOW - MOBILE APPLICATION CREATION GUIDE
                 Convert React Website into Android (APK) & iOS App
================================================================================

Because BillNow is already designed with a mobile-first UI (bottom navigation, 
touch targets, clean dimensions, and responsive layouts), converting it into a 
real installable mobile app is fast and straightforward.

There are TWO primary ways to convert BillNow into a mobile application:
  1. METHOD 1: Capacitor (RECOMMENDED) - Turns your React project into a true
     native Android Studio / Xcode project. Generates real .APK / .AAB files.
  2. METHOD 2: PWABuilder (FASTEST NO-CODE) - Generates an Android APK directly
     from your live website URL in 2 minutes.

--------------------------------------------------------------------------------
METHOD 1: CAPACITOR (RECOMMENDED FOR NATIVE APK / PLAY STORE)
--------------------------------------------------------------------------------
Capacitor wraps your React + Vite frontend into a native Android/iOS shell.
Your existing code, routing, and APIs work 100% identically, with access to 
native device features (camera, storage, push notifications).

PREREQUISITES:
  1. Node.js (v18+) and npm installed.
  2. Android Studio installed (Download from: https://developer.android.com/studio)
     - During Android Studio setup, install: "Android SDK", "Android SDK Command-line Tools",
       and "Android Build-Tools".
  3. Java JDK 17 or 21 (bundled inside Android Studio).

STEP-BY-STEP TERMINAL COMMANDS:

  Step 1: Open Terminal in the Frontend Folder
    cd d:\billnow\frontend

  Step 2: Install Capacitor Core and CLI
    npm install @capacitor/core @capacitor/cli

  Step 3: Initialize Capacitor
    npx cap init
    - App Name: BillNow
    - Package ID (App ID): com.billnow.app
    - Web Asset Directory: dist

  Step 4: Install Android & iOS Platforms
    npm install @capacitor/android
    npx cap add android

    (For iOS, requires a Mac with Xcode):
    npm install @capacitor/ios
    npx cap add ios

  Step 5: Point Frontend to Production Cloud Backend
    In frontend/.env (or frontend/.env.production):
      VITE_API_URL=https://<your-render-backend-url>.onrender.com

  Step 6: Build the React Application
    npm run build

  Step 7: Sync the Web Build to the Native Android Project
    npx cap sync

  Step 8: Open Project in Android Studio
    npx cap open android

  Step 9: Generate APK / Run on Phone
    In Android Studio:
    a) Connect your Android phone with USB Debugging enabled, OR start an Emulator.
    b) Click the green "Run" (Play) button to test on your phone.
    c) To generate a standalone APK:
       - Go to Menu -> Build -> Build Bundle(s) / APK(s) -> Build APK(s)
       - Android Studio will generate the APK at:
         frontend/android/app/build/outputs/apk/debug/app-debug.apk
       - You can transfer this .apk file to any phone and install it directly!

--------------------------------------------------------------------------------
CUSTOMIZING APP ICONS & SPLASH SCREEN FOR CAPACITOR
--------------------------------------------------------------------------------
To automatically generate icons and splash screens for all Android screen sizes:

  1. Create a 1024x1024 PNG logo named "icon.png" and place it in frontend/assets/
  2. Create a 2732x2732 PNG splash image named "splash.png" in frontend/assets/
  3. Run:
       npm install -g @capacitor/assets
       npx capacitor-assets generate --android
  4. Run:
       npx cap sync

--------------------------------------------------------------------------------
METHOD 2: PWABUILDER (FASTEST - NO CODING REQUIRED - 2 MINUTES)
--------------------------------------------------------------------------------
Since BillNow already has `manifest.webmanifest` and service worker `sw.js` 
configured, you can convert it into an Android APK online without installing 
Android Studio:

  1. Ensure your website is deployed on Vercel (e.g., https://billnow.vercel.app).
  2. Open https://www.pwabuilder.com in your browser.
  3. Enter your live website URL and click "Start".
  4. PWABuilder analyzes the site (PWA score will be Green/Ready).
  5. Click "Package for Stores".
  6. Under "Google Play / Android", click "Generate Package".
  7. Download the generated ZIP package:
     - Inside you will find:
       - A ready-to-test APK file (install on any Android device).
       - An AAB (Android App Bundle) file ready for Google Play Store upload.

--------------------------------------------------------------------------------
PUBLISHING TO GOOGLE PLAY STORE CHECKLIST
--------------------------------------------------------------------------------
When you are ready to publish BillNow on the Google Play Store:

  1. Google Play Console Account:
     - Sign up at https://play.google.com/console ($25 one-time fee).
  2. Generate Signed Release Bundle (AAB):
     - In Android Studio:
       Menu -> Build -> Generate Signed Bundle / APK -> Android App Bundle
       Create a new keystore (save your key password safely!).
  3. Store Assets Needed:
     - App Icon: 512x512 PNG
     - Feature Graphic: 1024x500 PNG
     - 4-8 Screenshots of the mobile screens (Home, Products, Add Product, Alerts)
     - Privacy Policy URL (can link to https://<your-site>/#privacy or your GitHub repo)
  4. Upload the .aab file to Play Console under "Production Release" and submit for review.
